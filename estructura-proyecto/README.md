# Estructura del proyecto

Aquí se va definiendo CodeAtlas por bloques funcionales y técnicos.

## Bloques actuales
- `arquitectura-general/`: decisiones globales de estructura
- `frontend/`: interfaz web y organización del cliente
- `backend/`: API, módulos y organización del servidor
- `usuarios-y-autenticacion/`: login, usuarios y settings
- `proyectos/`: listado, detalle y datos de proyecto
- `lector-de-archivos/`: entrada en `.md` y transformación interna
- `base-de-datos/`: entidades y relaciones principales

## Idea de trabajo
Cada carpeta recoge una parte concreta del sistema para poder diseñarlo con orden antes de implementarlo.
