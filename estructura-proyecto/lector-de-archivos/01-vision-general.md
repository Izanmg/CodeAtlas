# Lector de archivos

## Objetivo
Definir la primera parte de CodeAtlas: la lectura de archivos de entrada para poder representar una aplicación de forma visual.

## Idea general
La aplicación debe permitir cargar uno o varios archivos `.md` con un formato definido por CodeAtlas.

Estos archivos servirán para describir la estructura de una aplicación antes de que esté desarrollada o mientras se está planificando.

## Qué debe poder hacer esta parte
- recibir archivos `.md`
- leer su contenido
- interpretar la estructura definida en esos archivos
- transformar esa información en un formato interno entendible por CodeAtlas
- usar ese formato para generar una representación visual de la aplicación

## Qué puede describir el archivo
Según cómo definamos el formato, estos archivos podrán incluir información como:
- módulos
- pantallas
- relaciones entre partes
- flujos
- funciones principales
- estructura general de la aplicación
- partes de base de datos si hiciera falta

## Resultado esperado
El resultado de esta parte no es solo mostrar texto, sino convertir la definición del archivo en una representación visual clara dentro de la interfaz web.

## Notas
Este documento forma parte de la estructura del proyecto y no se plantea como un archivo de MVP aislado.
Aquí iremos definiendo cómo queremos que funcione realmente la aplicación por partes.
