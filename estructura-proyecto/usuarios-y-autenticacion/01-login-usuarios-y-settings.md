# Login, usuarios y settings

## Objetivo
Permitir varios usuarios dentro de la aplicación y separar sus datos.

## Funcionalidades base
- registro de usuario
- inicio de sesión
- gestión de sesión
- datos propios por usuario
- modificación de datos de cuenta

## Registro
Además del login, la aplicación tendrá una parte de registro.

Esto es necesario para que un usuario pueda crear su cuenta y acceder después a sus proyectos.

## Datos de usuario planteados inicialmente
- nombre de usuario
- contraseña
- fecha de nacimiento

Más adelante se podrá decidir si conviene añadir email, rol, foto o más campos.

## Ajustes de usuario
El usuario debe poder modificar al menos:
- nombre de usuario
- contraseña
- fecha de nacimiento

## Razón de esta parte
Aunque no estuviera completamente detallado en los apuntes iniciales, encaja con la idea de sistema de gestión web y deja la aplicación mucho mejor preparada para uso real y crecimiento futuro.
